# Minigame Sprites

This directory contains sprites for the minigame scene.

## Required Sprites

- `clearing.png` - Grass texture for the playable clearing area (32x32 pixels, tileable)
- `forest.png` - Forest/tree texture for the forest boundaries (32x32 pixels, tileable)
- `forest_floor.png` - Forest floor texture for the background (32x32 pixels, tileable)

## Sprite Specifications

All sprites should be:
- 32x32 pixels
- Tileable (seamless when repeated)
- PNG format with transparency support
